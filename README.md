# WordPress Theme Helpers

A collection of scripts to scaffold WordPress themes quickly.

## Scripts

### `create-new-tailwind-theme.cmd`

Creates a new WordPress theme pre-configured with [Tailwind CSS v3](https://v3.tailwindcss.com/).

**Requirements**

- Windows (uses `.cmd` scripts)
- [Node.js](https://nodejs.org/) and npm on your PATH

**Usage**

Run the script from the directory where you want the theme folder created (typically your WordPress `wp-content/themes/` directory):

```cmd
create-new-tailwind-theme.cmd
```

You will be prompted for a theme name. The script will:

1. Create a `<theme-name>-dev/` folder
2. Initialize npm and install Tailwind CSS v3
3. Generate a `tailwind.config.js` scoped to WordPress PHP and JS files
4. Create the required WordPress theme files (`style.css`, `functions.php`, `header.php`, `footer.php`, `index.php`)
5. Add `watch.cmd` and `build.cmd` helpers

**Generated theme structure**

```
<theme-name>-dev/
├── assets/
│   ├── css/
│   │   ├── tailwind.css   # Tailwind directives (input)
│   │   └── style.css      # Compiled output (generated by watch/build)
│   └── js/
├── footer.php
├── functions.php
├── header.php
├── index.php
├── style.css              # WordPress theme header
├── tailwind.config.js
├── watch.cmd              # Runs Tailwind in watch mode
└── build.cmd              # Compiles CSS and packages theme as a zip
```

**Next steps after running the script**

```cmd
cd <theme-name>-dev
watch.cmd
```

Then activate the theme in **WordPress Admin > Appearance > Themes**.

### `build.cmd` (generated inside each theme)

Run from within the theme folder to produce a release-ready zip:

```cmd
build.cmd
```

The script will:

1. Compile Tailwind CSS to `assets/css/style.css`
2. Strip the `-dev` suffix from `Theme Name` and `Text Domain` in `style.css` (restored after packaging)
3. Create `<theme-name>.zip` in the parent directory, excluding development files (`node_modules/`, `*.cmd`, `package.json`, `package-lock.json`, `tailwind.config.js`, `assets/css/tailwind.css`)
